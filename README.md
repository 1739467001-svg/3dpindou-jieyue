> **2026 影石 Insta360 Bold Maker 智能影像挑战赛 · AI+影像产品开发赛道**

## 一、一句话介绍

把影石全景相机拍下的 360° 世界，变成一颗颗可以拿在手里的**立体拼豆**：上传一张全景图（或 360 视频、一句文字描述），浏览器端的 AI 估计深度、反投影成点云、体素化并匹配拼豆色板，几秒钟后得到一个可以 **360° 旋转、逐颗拼装**的立体作品，并附带**分层施工图纸**和**材料清单 BOM**。

## 二、痛点与机会（调研结论）

| # | 发现 | 数据/证据 |
|---|------|----------|
| 1 | 拼豆是当红手工品类，用户基数极大 | 小红书话题浏览 **70 亿+**、讨论量 1700 万+；抖音春节拼豆订单同比 **+9018%**；TikTok Shop 单 SKU 月销 42.6 万件 |
| 2 | 核心人群是 Z 世代/职场人，动机是解压与情绪消费 | 多篇行业报道一致；第二大场景是亲子与礼物定制 |
| 3 | **所有现有工具都只输出 2D 平面图纸** | 调研了 pindouai.app、bitbead.app、perler-beads.org、Perler Studio 等十余个国内外生成器，无一支持立体图纸 |
| 4 | 立体拼豆需求真实存在，但图纸全靠手工 | Etsy 有 3D 图纸售卖；国内主流做法是 MagicaVoxel 手工建模→拆层→手动画每层网格，一个 6 面板小房子画图要 4–6 小时 |
| 5 | 拼之前用户最需要三样东西：带色号的施工图、材料清单 BOM、**色号能对上自己手里的豆子** | 「杂牌编码对不上」是被反复吐槽的痛点；各品牌色板（MARD 291 / COCO 291 / Perler 95 / Hama）互不通用 |
| 6 | 影石用户拍了几百 TB 全景素材，剪完视频就沉睡在硬盘里 | 360 素材缺少「把玩/再创作」级的消费出口 |

**市场空白：把 360° 全景/照片自动转成「可拼的立体图纸」——没有任何工具在做。**

## 三、产品方案

### 3.1 核心流程（全浏览器本地运行，零后端）

│ 360 视频  │      │ V2 (int8 ONNX) │      │ ×深度→点云   │      │ 孤立体素剔除 │      │ 色板匹配     │

### 3.2 功能清单

**素材入口（4 种）**
- 全景图片上传（ERP 等距柱状投影 JPG/PNG；普通照片也可，AI 按 360 画面处理）
- 360 视频上传：自动抽 8 个关键帧，可逐帧选用或**多帧融合**（点云叠加，适合相机绕拍素材）
- 6 个内置程序化 360 场景（蘑菇小屋/机器人/城堡/森林/星球/茶壶花园），断网可演示
- **文字造景**：一句描述 → 生成 360° 全景 → 直接进入拼豆流程

**3D 拼豆编辑器（核心工具台）**
- 2D 钉板画布：画笔（带笔刷大小）/ 橡皮 / 油漆桶 / 取色器 / 换色 / 直线 / 矩形，滚轮缩放、拖拽平移
- 图层系统：新增 / 复制 / 删除 / 清空 / 上下移动，每层独立编辑，3D 实时同步
- 对称工具：左右镜像、前后镜像、4 路径向对称（做玩偶/花朵/雪花）
- 撤销 / 重做（40 步历史）、色号显示开关、29×29 钉板边界辅助线
- 快速模板：收纳盒 / 小人偶 / 球体 / 爱心名牌，一键生成可修改的立体雏形
- AI 作品可一键「进入编辑器精修」，色板自动就近映射到品牌色号
- 真实品牌色板：MARD 291/221、COCO 291、Artkal 176、Artkal Mini 221、Perler 117、Hama 89 共 **1,406 个真实色号**（bitbead 开源数据集，CC BY 4.0）

**熨烫模拟器（3D 现实模拟）**
- 完整熨烫动画：熨斗往返走熨 + 半透明熨烫纸 + **逐颗渐进熔合**（熨斗扫过的豆子才融合）
- 温度（100–200°C）× 每面时间 × 单/双面 → 实时计算熔合等级（未熨烫/轻熨/标准熨/全熔）
- 3D 可视化：豆子随熔合胀大、中心孔逐渐闭合、颜色加深，熨斗下方有暖色热光
- **冷却机制**：熨完的层真实计时冷却 10 秒，期间泛暖光；未冷却就叠层会被告知「会烫坏豆子、导致移位」
- 工艺警示：温度过高（黄化不可逆）、停留过久（孔闭合导致 tab 插不进 slot）、温度过低（崩开）、必须干烫

**制作看板与结构工艺**
- 每层工艺状态条：⬜空 / 🧩已摆未熨 / 🔥冷却中 / ✅已熨已冷 / ⚠️全熔，点击跳层
- **互锁 tabs 自动生成**：当前层四边每 N 格生成 1 格凸榫（mating 片对应位置留空作 slot，先摆好后点胶）——立体组装的标准工艺
- **空心省豆**：内部层一键空心化（只留边框），实时显示节省豆数（实测小人偶省 560 颗）
- 预估重量（2.6mm≈0.028g/颗，5mm≈0.11g/颗）、每层所需 29×29 钉板数
- 快速模板：收纳盒 / 小人偶 / 球体 / 爱心名牌（颜色按 CIEDE2000 就近匹配到所选品牌色板）

**结构安全检测**
- 悬空豆检测：标出下方没有支撑的豆子（现实里会掉），2D 视图红色警示 + 3D 孔染红 + 数量统计

**工坊交互（3 种模式）**
- 👁 观察模式：360° 自由旋转、缩放、自动旋转；按模型包围盒智能取景
- 🧱 逐层模式：从底层向上自动建造动画，进度条可拖动擦洗
- ✋ 逐颗模式：一颗颗放豆（点击或空格），落豆弹性动画 + WebAudio 落豆音效 + 幽灵豆指引，实时进度与完成庆祝
- 快捷键：`1/2/3` 切模式、`空格` 放豆、`R` 复位、`S` 自转

**AI 辅助**
- ✨ AI 自动调参：分析深度直方图，自动推荐「背景剔除」与「主体深度」后直接拼豆
- 🎴 分享卡片：3D 截图 + 作品统计 + 色板，社交平台比例一键下载（晒图即传播）
- 示例场景参数预设：每个内置场景带推荐参数，第一次点开就好看
- 首次访问引导：新用户一眼知道从哪开始

**作品档案与导出**
- 统计：豆子总数、用到颜色数、层数、成品尺寸（cm）、预计工时、难度、每层所需钉板数
- 🖼 分层图纸 PNG：每层一张网格图，格子内直接印色号，打印即可照拼
- 📋 材料清单 CSV：每种色号数量与占比，照单买豆
- 💾 作品 JSON：模型保存与再加载

**拍摄指南（怎么拍）**
- 影石 3DGS 拍摄规范结构化：设备参数卡（X5 / 8K30fps / 运动 HDR / 1–2m / <1m/s / 70–80% 重叠 / 闭环）
- 拍摄路径模拟器：环绕 / 螺旋 / 井字三种路线的动画演示
- 六字诀：慢、近、绕、叠、饱、环
- 拍摄自检清单：12 项打分（100 分制）
- 影石开发接口路线图：Camera SDK（实时预览 + OnGyroData 姿态）、Media SDK（双鱼眼→ERP 实时拼接）、OSC（WiFi 远程控制 + 机内拼接下载）

**移动端适配**
- 汉堡导航菜单、48px 触控目标、加高滑块（32px）、舞台自动滚入视野、toast 置底、触屏去粘滞 hover
- 手机浏览器直接可用（触屏旋转/缩放/逐颗放置均已验证）

**AI 助手**
- 右下角常驻：拼豆技巧、拍摄参数、图纸拼装、熨烫、产品使用
- 默认离线知识库；填入阿里百练 API Key 即切换千问大模型实时回答

## 四、AI 在哪些环节（赛题「AI 重新定义怎么拍和怎么看」对照）

| 环节 | AI 技术 | 实际作用 |
|------|---------|---------|
| 怎么看 · 深度之眼 | Depth Anything V2（ONNX Runtime Web，WebGPU/WASM 自动降级） | 单张平面全景图 → 带深度的球面场景；流程与影石研究院 **DAP**（ERP→depth→point cloud）同构 |
| 怎么拼 · 配色引擎 | CIELAB + **CIEDE2000** 感知色差匹配 + 贪心限色 | 每个体素颜色匹配到真实拼豆色板，解决「色号对不上手里豆子」；支持导入 MARD/COCO 等官方 CSV 色板 |
| 怎么拍 · 摄影教练 | 影石 3DGS 拍摄指南结构化 + 路径模拟 + 自检打分 | 把「拍不好就没法重建」的隐性知识变成可执行清单；下一步接 Camera SDK 预览流 + IMU 实时提示 |
| 怎么想 · 创意助手 | 离线知识库 + 千问大模型（DashScope 兼容接口） | 全程自然语言问答 |
| 怎么来 · 文字造景 | 程序化全景生成（DiT360「文字→全景」理念的离线实现） | 没有相机也能玩立体拼豆 |

## 五、技术实现

- **纯静态、零后端**：`index.html` + ES Modules + import map，`node serve.mjs` 或任意静态服务器即可运行
- **3D 渲染**：Three.js r186，InstancedMesh 单 draw call 渲染上万颗豆子；实例矩阵按建造顺序写入，`mesh.count = K` 即「已拼 K 颗」，进度控制零成本
- **AI 推理**：onnxruntime-web 1.30，int8 量化模型 26MB；`executionProviders: ['webgpu','wasm']` 自动降级；COOP/COEP 响应头启用多线程 WASM
- **几何**：ERP 反投影（`θ=2π(u+0.5)/W−π, φ=(0.5−(v+0.5)/H)π, P=depth·d`）→ 点云 → N³ 体素累积 → 自适应阈值去散点 → 面相邻孤立体素剔除
- **性能**：反投影/体素化/配色在主线程完成（10 万级点约 100ms，48³ 体素化约 2–40ms）；模型与运行时全部内置（vendor 85MB + 模型 26MB ≈ 111MB），断网可演示
- **隐私**：所有计算在本地浏览器完成，素材永不上传

## 七、本地运行

```bash
# 方式一：内置服务器（自动带 COOP/COEP 头，启用多线程 AI 推理）
node serve.mjs 8080

# 方式二：任意静态服务器
python3 -m http.server 8080
# 然后打开 http://localhost:8080
```

> 注：`file://` 直开不可行（浏览器安全策略拦截 wasm/模型加载），必须通过 http 服务。
> 快捷键：`1/2/3` 切模式（观察/逐层/逐颗）、`空格` 放豆、`R` 复位、`S` 自转。
> 自动化测试（需先启动服务器）：`node tools/e2e-critical.mjs` / `e2e-extended.mjs` / `e2e-edge.mjs` / `e2e-fuse.mjs` / `e2e-export.mjs`（依赖 `npm i -D playwright`，仅开发用；**应用本身零依赖**，`node_modules` 不参与部署）。

## 七·五、部署到云服务器

完整清单见 [`deploy/checklist.md`](deploy/checklist.md)，要点：

```bash
# 一键部署（服务器需已装 nginx 并按清单配好证书）
./deploy/deploy.sh root@服务器IP /var/www/beadorbit
```

- **必须 HTTPS**：WebGPU 只在安全上下文（https/localhost）可用；纯 HTTP 会退到 WASM 单线程，慢 5–10 倍
- **必须带 COOP/COEP 响应头**：否则 ORT 多线程 WASM 不生效（`deploy/nginx.conf` 已配好）
- `deploy/nginx.conf`：nginx 模板（证书、缓存、隔离头）；`deploy/vercel.json`：Vercel 零运维备选
- 交付体积约 111MB（vendor 85MB + 模型 26MB），首次访问后全部走缓存
- 现场演示首选笔记本本地 `node serve.mjs`（localhost 即安全上下文，不依赖会场网络）
